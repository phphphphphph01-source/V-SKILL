# V-SKILL UI Upgrade

This build keeps the existing Flask/SQLAlchemy application and adds a game-inspired, smooth UI layer.

## Added
- Global scroll progress indicator
- Page/card reveal animations using IntersectionObserver
- Button ripple feedback
- Modern glass/dark visual treatment and responsive layout
- Improved cards, buttons, forms, mission choices and result presentation
- Mission timer HUD with danger state
- Mission answer/hint animations
- Mission completion result card
- Discovery landing improvements
- Reduced-motion accessibility support

## Notes
The visual layer is intentionally dependency-light. The existing application routes, APIs and database are preserved.
